# how_to_make_life

An essay on building persistent artificial life: fifteen aspects of the system,
and what each one commits you to.

**Read it:** https://eeman1113.github.io/how_to_make_life/

## What is in here

```
web/        Next.js app (App Router, static export) that renders the essay
theology.md the essay source
figures/    the seven diagrams at full resolution
```

## The figures

Every word of handwriting in the diagrams is generated by
[handwriter](https://github.com/Eeman1113/handwriter), a recurrent
mixture-density network that emits one pen movement at a time, run headless in
Node. The shapes, arrows, highlighter and brush strokes are vector geometry
generated alongside it. The coloured objects are hand-drawn sketchbook
elements, keyed to transparency and layered in.

## Running it

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to web/out
```

Deployment is automatic: pushing to `main` runs `.github/workflows/deploy.yml`,
which builds with the repo name as `basePath` and publishes to GitHub Pages.
